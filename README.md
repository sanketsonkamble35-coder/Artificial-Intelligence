# AI Practicals in Java
This repository contains Java implementations of Artificial Intelligence laboratory practicals.

## Practical 3: Rule-Based Chatbot
A simple chatbot that uses predefined rules and string matching to respond to user input.
**File:** `Chatbot.java`

## Practical 4: Intelligent Number Guessing Agent
An intelligent agent that guesses a number between 1 and 100 using binary search and user feedback.
**File:** `NumberGuessingAgent.java`

## Technologies Used
* Java
* Object-Oriented Programming fundamentals
* Binary Search
* Rule-Based Systems

## How to Run
Compile and run the chatbot:

bash
javac Chatbot.java
java Chatbot

Compile and run the number guessing agent:

bash
javac NumberGuessingAgent.java
java NumberGuessingAgent
